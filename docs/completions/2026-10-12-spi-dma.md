## 接口、兼容性与所有权

- `dev_spi_ops_t` 的 `claim/release/is_owner` 可选但必须成组全空/全有；claim 非递归、
  不等待。全空只保留 wrapper 状态检查，不能提供 RTOS task owner 保证。
- SPI 静态 index 变为 0/1/2 共 3 个；宿主 index 0/1/2 分别是 SPI4/SPI2/SPI3。
  迁移时重编 custom ops、更新 resource initializer、getter/table/loop；不兼容旧结构布局。
- `pins[3]` 按 SCK/MISO/MOSI 独立提供 port/pin/AF/clock hook，RX/TX DMA descriptor
  属于 adapter/board。任一 DMA 存在则要求两条均有效、不同 handle/stream/IRQ、normal
  mode、正确方向和 SPI IRQ；两条都为空才保留 polling。
- DMA 要求完整 opaque host sync ops：claim/release/is_owner/ready/drain/wait/
  notify_from_isr/get_ms/buffer_valid。框架无 FreeRTOS 类型；H743 使用静态 mutex 与
  binary semaphore，核查当前 task owner，拒绝 ISR、屏蔽 IRQ 或 scheduler 非运行上下文。
- begin 先 claim 再拉低 CS，多个 frame 同步完成且保持 CS；owner end 同一 CS 才能拉高
  并 release。CS 拉高失败保留状态。手动多帧失败路径仍须 end；transact 会尝试 end，
  保留优先发生的 frame 错误。其他 task 不得 frame/end 该事务。
- API 长度始终为字节；8 bit frames = bytes，16 bit 要求偶数长度和 2 字节地址对齐，
  frames = bytes / 2，DMA alignment 改为 halfword。等长非零双向 full duplex，
  不等长先 TX 后 RX，共享一个 frame deadline；多帧各有自己的 timeout。
- DMA phase drain 后进入 ACTIVE。HAL completion/error 经唯一 callback owner 发布
  COMPLETED/ERROR 并 ISR 通知；重复/迟到通知不覆盖 terminal result。timeout 进入
  TIMED_OUT；失败或超时同步 abort SPI 与双 DMA，清 pending IRQ/drain，成功后恢复 IRQ。
  abort/deinit 失败 faulted 并拒绝新传输；H743 stream 仍 enabled 时调用 Error_Handler。
  调用返回前 buffer 必须保持有效，不能提前释放或复用。
- H743 buffer policy 拒绝 DTCM；D-Cache 开启时拒绝所有 DMA buffer，返回
  `USR_ERR_UNSUPPORTED`，没有 cache maintenance/bounce buffer。当前白名单范围见
  [宿主接入](../specs/host-integration.md)。
- normal DMA completion 由 HAL 启用 SPI EOT，唯一 SPI vector/HAL IRQ/callback owner
  才发布完成；DMA stream IRQ 不能独立提前释放 CS。MSP 也由宿主唯一 hook 委派 adapter。

## 宿主边界

具体 board resource 与验收留在宿主 `doc/2026-10-12-spi-dma.md`：DMA2 stream0/1
是 SPI2 RX/TX，2/3 是 SPI3 RX/TX，4/5 是 SPI4 RX/TX，6 是 USART1 RX；ADC1/2/3
保持 DMA1 stream0/1/2。SPI3 PB3/PB4 使用 AF6，PB5 使用 AF7；PB6/PB7 为逻辑 CS，
I2C1 占位 resource 的 instance 置 NULL 解除冲突。旧生成 SPI init 未在启动链调用，
旧 SPI2/DMA1 stream3 IRQ 不再分发到 legacy owner。`.ioc` 已弃用，未用作配置或验证输入。

## 烧录与运行边界

最终 `USR_SPI_DIAGNOSTICS=OFF` Debug 镜像执行 `python tool/flash.py --adapter stlink`
返回 `Error: open failed` / `Debugger not connected (check USB)`，未得到 `Verified OK` 或
`Resetting Target`，因此最终正常镜像本轮未确认烧录成功。此前临时 `USR_SPI_DIAGNOSTICS=ON`
镜像曾编程校验成功；该结果只证明编程，不代表最终镜像或 SPI 通信。

临时诊断观察到 SPI4 DMA/EOT completion 计数增长；屏蔽 SPI4 EOT IRQ 后 timeout 增加，
后续传输恢复，faulted 保持 0、HAL SPI 回到 READY、HAL ErrorCode 为 0。FRAM RDID 返回
`USR_ERR_DATA` 且 buffer 全为 `0x00`，识别验收失败；SPI2/SPI3 无物理回环接线，尚未完成
真实 TX、RX 和 full-duplex 验收。host 测试覆盖的 timeout/error/abort、deinit/reinit、
8/16 bit、DTCM/D-Cache 路径仍不等同于目标板实测。
