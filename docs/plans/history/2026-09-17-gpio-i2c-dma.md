# GPIO, I2C, and DMA Resource Decoupling Implementation Plan

> **For agentic workers:** Execute this plan task by task. After every hardware
> ownership stage, run the structural gate and firmware build, then request an
> independent high-reasoning review. Resolve all Critical and Important
> findings before continuing.

**Goal:** Remove the remaining active GPIO, I2C1, and DMA CubeMX initialization
dependencies using resource-consumer ownership.

**Architecture:** Port-owned logical GPIO and I2C1 resources use static
descriptor/context tables. Core retains only explicit legacy resources and HAL
dispatcher shells. DMA channels and setup remain private to ADC/UART consumers.

**Spec:**
`docs/superpowers/specs/2026-09-17-gpio-i2c-dma-resource-decoupling-design.md`

## Task 1: Freeze Structural Acceptance Tests

- [ ] Add `scripts/peripheral_resource_structure_test.py` with independent
  `gpio`, `i2c`, and `dma` stages.
- [ ] Run each stage against the baseline and record the expected failure.
- [ ] Preserve the baseline firmware build result and warning count.

## Task 2: Move Logical GPIO Resources To The Port Owner

- [ ] Extend the port GPIO descriptor with clock, mode, pull, speed, initial
  level, and IRQ metadata.
- [ ] Initialize logical pins from descriptors, writing output defaults before
  `HAL_GPIO_Init()`.
- [ ] Bind PA/PB clock callbacks and all seven logical resources in
  `board_support.c`.
- [ ] Initialize the GPIO device during board initialization.
- [ ] Route EXTI1 by IRQ number through the port adapter.
- [ ] Reduce Core GPIO initialization to LED2 and legacy safe-state pins and
  remove the `MX_GPIO_Init` symbol.
- [ ] Run `python scripts/peripheral_resource_structure_test.py gpio`.
- [ ] Run `python scripts/build.py` and compare warnings with baseline.
- [ ] Request an independent `gpt-5.6-sol` `xhigh` GPIO review and resolve all
  Critical/Important findings.

## Task 3: Move I2C1 Handle And MSP Ownership To The Port

- [ ] Add a port-private I2C1 resource/context table and opaque context getter.
- [ ] Implement HAL init, filters, deinit/recovery, ownership probe, and MSP
  init/deinit in `port_hal_i2c`.
- [ ] Convert Core `i2c.c` into an MSP dispatcher shell.
- [ ] Remove `hi2c1`, `MX_I2C1_Init`, and the platform reinit callback.
- [ ] Bind the opaque I2C context in `board_support.c`.
- [ ] Add and call `dev_i2c_init()` before the HDC1080 uses the bus.
- [ ] Remove stale I2C reset/resume ownership from `usart_if.c`.
- [ ] Run `python scripts/peripheral_resource_structure_test.py i2c`.
- [ ] Run `python scripts/build.py` and compare warnings with baseline.
- [ ] Request an independent `gpt-5.6-sol` `xhigh` I2C review and resolve all
  Critical/Important findings.

## Task 4: Move DMA Controller Clock Responsibility To Consumers

- [ ] Enable DMA1/DMAMUX1 clocks in UART MSP before UART RX DMA setup.
- [ ] Enable DMA1/DMAMUX1 clocks in ADC MSP before ADC DMA setup.
- [ ] Remove active `MX_DMA_Init` calls and stale `MX_DMA_*` declarations.
- [ ] Remove obsolete conditional callers that can reintroduce undefined MX
  DMA ownership.
- [ ] Keep channel IRQ routing and per-channel NVIC ownership unchanged.
- [ ] Run `python scripts/peripheral_resource_structure_test.py dma`.
- [ ] Run `python scripts/build.py` and compare warnings with baseline.
- [ ] Request an independent `gpt-5.6-sol` `xhigh` DMA review and resolve all
  Critical/Important findings.
